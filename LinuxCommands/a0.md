
# Linux Commands — Quick Revision Notes

## 1. Command Structure

A Linux command generally follows:

```bash
command_name [options] [arguments]
```

- **Command name:** Program to execute (e.g., `cat`).
- **Options:** Modify command behaviour (e.g., `-n`, `--number`).
- **Arguments:** Files or values on which the command operates (e.g., `abc.txt`).

Options can have:
- Short form: `-n`
- Long form: `--number`

## 2. `cat` — Display File Contents

Displays the contents of a file in the terminal.

```bash
cat abc.txt
```

**Output:**
```text
Hello
This is simple text file
Bye
```

### Number the output lines

```bash
cat -n abc.txt
```

Alternative:

```bash
cat --number abc.txt
```

Both commands display file contents with line numbers.

**Remember:**
- `-n` = Short option
- `--number` = Long option

## 3. `ncal` — Display Calendar

Displays a calendar in the terminal.

```bash
ncal
```

Displays the current month's calendar by default.

### Display a specific month and year

```bash
ncal 10 2023
```

Displays October 2023.

### If ncal is not installed (Ubuntu)

```bash
sudo apt update
sudo apt install ncal
```

Then execute:

```bash
ncal
```

```bash

```
