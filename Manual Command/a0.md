
# Chapter 2: Manual Command (`man`)

## 1. Introduction

- `man` stands for Manual.
- Used to access Linux command documentation.
- Explains syntax, options, arguments and usage.

## 2. Syntax

```bash
man command_name
```

## 3. Examples

```bash
man cat
man cp
man ls
man ncal
```

## 4. Manual Page Sections

| Section | Description |
|---|---|
| NAME | Command name and purpose |
| SYNOPSIS | Command syntax |
| DESCRIPTION | Detailed explanation |
| OPTIONS | Available options |
| SEE ALSO | Related commands |

## 5. Navigation Inside Manual

| Key | Function |
|---|---|
| ↑ / ↓ | Move up/down |
| Space | Next page |
| b | Previous page |
| /keyword | Search keyword |
| n | Next search result |
| q | Exit manual |

## 6. Practical Example

```bash
man cp
```

- NAME: `cp` – Copy files and directories.
- SYNOPSIS: Shows command syntax.
- DESCRIPTION: Explains how copying works.
- OPTIONS: Lists available options.

## 7. Quick Revision

- `man` = Manual
- `man cat` = Open cat documentation.
- `man cp` = Open cp documentation.
- `/keyword` = Search inside manual.
- `q` = Exit manual.
